# Paper figures

Final figures for the manuscript. Each is regenerable from a script under
[`scripts/`](scripts/) against data already in the working tree (some git-ignored) —
see [`scripts/README.md`](scripts/README.md) for the per-figure mapping and inputs.

| Figure | Generated by | Self-contained? |
|--------|--------------|-----------------|
| `theory_schematic.png` | `scripts/make_theory_schematic.py` | ✅ (no data) |
| `cn_hea_fps_overlap_combined.png` | `scripts/combine_fps_overlap.py` | ✅ (Jaccard CSVs) |
| `cn_umap_degeneracy.png` | `scripts/cn_umap_energy.py` | ✅ (cached embeddings) |
| `hea_frame_fingerprints.png` | `scripts/hea_frame_fingerprints.py` | ✅ (2-frame histograms) |
| `hea_umap_degeneracy.png` | `scripts/make_umap_degeneracy_expanded.py` | ✅ (cached embeddings; no `umap` needed) |
| `cn_fps_selection_density.png` | — | ⚠️ image only |
| `cn_element_switching_graphite.png` | — | ⚠️ image only |

The two image-only figures have no source script that writes those exact filenames
(likely renamed from another output or produced interactively).

## Regenerate one

```bash
cd figures/scripts
python3 make_theory_schematic.py        # writes ../theory_schematic.png
```

Related figures with their own directories: the element-switching figure
(`../element_switching/cn_switching_image/`), the HEA latent-space figure
(`../hea_study/latent_space_visuals_expanded/`), and the test-error figures
(`../models/test_errors/`, `../hea_study/test_errors/`).

`data/` (git-ignored) holds the figure inputs (Jaccard CSVs, fingerprint / UMAP
NPZ, the 2-frame histogram trees).
